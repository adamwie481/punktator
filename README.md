# Punktator

Prosty licznik punktów na Androida.

Funkcje: dowolna liczba graczy, nazwy, +0,5/+1/+2/+5, wartości własne, odejmowanie, cofnięcie ostatniej operacji i ranking końcowy.

## GitHub
1. Wrzuć zawartość tego katalogu do repozytorium.
2. Wejdź w **Actions**.
3. Wybierz **Build Android APK**.
4. Kliknij **Run workflow** albo poczekaj na automatyczny build po commit.
5. Po zakończeniu otwórz wykonanie workflow i pobierz artefakt **punktator-apk**.
6. Rozpakuj ZIP i zainstaluj `app-debug.apk`.
